# Marketing Campaign Performance Prediction

## 📌 Project Overview

This project focuses on analyzing marketing campaign data and building machine learning models to predict:

1. **Revenue generated by marketing campaigns (Regression)**
2. **Profit/Loss outcome of campaigns (Classification)**

The goal is to help businesses understand campaign performance, identify profitable strategies, and use machine learning to support marketing decisions.

The project includes:

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Outlier handling
* Machine learning model development
* Model evaluation
* Model comparison
* Deployment using Streamlit

---

# 🎯 Objectives

The main objectives of this project are:

* Clean and preprocess marketing campaign datasets

# ⚙️ Feature Engineering

New features were created to improve model performance.

### Marketing Metrics

## Click Through Rate (CTR)

Measures how many users clicked after viewing an impression.

```
CTR = Clicks / Impressions
```

## Conversion Rate

Measures how many clicks resulted in conversions.

```
Conversion Rate = Conversions / Clicks
```

## Lead Conversion Rate

Measures how many leads became conversions.

```
Lead Conversion Rate = Conversions / Leads
```

## Cost Per Click (CPC)

Measures advertising cost efficiency.

```
CPC = Acquisition Cost / Clicks
```

## Engagement Score

A combined metric representing campaign engagement.

# 🤖 Machine Learning Models

## Regression Task

### Target Variable

```
Revenue
```

The objective was to predict campaign revenue.

### Models Used

* Linear Regression
* Ridge Regression
* Lasso Regression
* Decision Tree Regressor
* Random Forest Regressor
* Gradient Boosting Regressor

### Evaluation Metrics

The regression models were evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)

The best regression model was selected based on the highest R² score.

---

# Classification Task

## Target Variable

A new target feature was created:

```
profit_flag
```

Mapping:

```
ROI > 0  → Profit
ROI <= 0 → Loss
```

Encoded values:

```
0 = Loss
1 = Profit
```

---

## Classification Models Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

---

## Handling Class Imbalance

Class imbalance was handled using:

```
class_weight="balanced"
```

This helped models give more importance to minority classes.

---

## Classification Evaluation Metrics

Models were compared using:

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix

The best classification model was selected based on F1 Score.
